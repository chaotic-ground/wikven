WikiHiero writes Ancient Egyptian hieroglyphs. Like a formula it wants no program beside MediaWiki, but unlike one it is not bundled, so a site says where to fetch it.

The name of Ramesses II:

Each sign is a small picture the extension carries. The build copies the ones a page uses into the site beside the page, so the reader fetches them from wherever the site is published and from nowhere else.

What a site declares

extensions:
  - wikihiero
config:
  WikvenRepositories:
    wikihiero:
      repository: https://github.com/wikimedia/mediawiki-extensions-wikihiero.git
      commit: 1a4f3d0456c5f1671b43da7e04426153f4db4eca

Lowercase, both times. A name in either place is a directory rather than a title, and this extension's directory is lowercase where it comes from — its own installation notes say wfLoadExtension( 'wikihiero' ) — with that spelling written into where it looks for its pictures. Most extensions are spelled as they are titled, and this one is not. See the WikvenRepositories map for the other ways to name a source, and Extensions for what a fetched extension is.

Writing hieroglyphs

<hiero>ra-ms-s-sw</hiero>

The codes between the tags are Gardiner's sign list — N5 is the sun, A1 a seated man — and a sign with a common reading may be written by that reading instead, as ra is written above. - sets signs side by side, : stacks them, and * joins them into one group. WikiHiero's own page has the rest.
