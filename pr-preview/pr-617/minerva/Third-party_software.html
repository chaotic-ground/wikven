Wikven is GPL-3.0-or-later, and what it hands you to run carries other people's software besides. This page names that software and the license each project publishes it under. It is reference for deciding what to build with and what to redistribute; none of it is anything you install yourself.

It is not the Licenses page. That one is written by every build and names what your published pages load — MediaWiki's scripts, and the styles and scripts of the skins and extensions your site enables. This page is about the tooling those pages are baked with, which your readers never receive.

The Docker image

Everything below is inside ghcr.io/chaotic-ground/wikven, and its own license text comes with it. The image also keeps MediaWiki's COPYING where MediaWiki puts it.

Component License Why it is there
MediaWiki, with the skins and extensions it bundles GPL-2.0-or-later Renders every page. The image is built on mediawiki:1.46.0-fpm-alpine.
PHP PHP License 3.01 Runs MediaWiki. From that same base image.
SifterSearch GPL-3.0-or-later The search a site of plain files can still serve.
Pagefind MIT The index and the search widget SifterSearch ships.
Translate GPL-2.0-or-later Translated pages, and the translate commands.
UniversalLanguageSelector GPL-2.0-or-later OR MIT The language picker, and the webfonts a build can bake in.
Spyc and composer/installers MIT Required by Translate.
Composer MIT Installs those two while the image builds.

The standalone binary

The binary is compiled from the image's own tree, so everything above is in it too. Compiling adds the server it runs on:

Component License Why it is there
FrankenPHP MIT Compiles PHP, MediaWiki and Wikven into the single executable.
Caddy Apache-2.0 The server FrankenPHP is built on. wikven serve is Caddy.
caddy-cbrotli MIT A Caddy module the FrankenPHP build links in.
Mercure and Vulcain AGPL-3.0 Caddy modules the FrankenPHP build links in. Neither is reached by a bake or by wikven serve.

The library versions the compile pulls are chosen by static-php-cli, which the build fetches at its current nightly rather than a pinned release, so the exact set moves with the day a binary was built.

Where the license texts are

Each component's full text ships with the artifact that carries it, which is what these licenses ask for; nothing here stands in for that. Where you want the canonical copy, the project's own page above is it.
