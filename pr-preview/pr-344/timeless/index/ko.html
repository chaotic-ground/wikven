Wikven은 Wikipedia를 구동하는 소프트웨어인 MediaWiki를 기반으로 한 정적 사이트 생성기입니다. 위키텍스트 디렉터리를 평범한 HTML 사이트로 바꿔 주는데, 어디서나 호스팅할 수 있고 구동할 서버나 데이터베이스가 필요 없습니다. 이 문서 사이트 또한 Wikven으로 만들었습니다.

콘텐츠가 이미 MediaWiki 위키텍스트이거나, MediaWiki의 틀·파서 함수·소도구·확장 기능은 그대로 쓰면서 실행할 것이 없는 정적 결과물을 원할 때 Wikven이 제격입니다. 프로젝트 문서 사이트, 평범한 HTML로 열람하는 보관용 위키, 개인 위키 같은 용도죠. Hugo나 MkDocs 같은 범용 정적 사이트 생성기와 달리 Wikven은 MediaWiki로 진짜 위키텍스트를 렌더링하므로, 위키텍스트에 익숙하다는 것을 전제합니다 (장단점은 위키텍스트를 쓰는 이유 참고).

Wikven을 설치하는 세 가지 방법(단독 실행 바이너리, Docker 이미지, 소스에서 빌드)은 설치 문서에서 다루며, 첫 사이트를 만들려면 시작하기로 이어집니다.

지원하는 기능

Wikven에서는 MediaWiki의 다음 기능을 쓸 수 있습니다.

  • Wikitext 문서 (문서 참고)
  • 틀
  • 위키미디어 공용이나 로컬 파일에서 가져온 이미지
  • 자바스크립트 (MediaWiki:Common.js와 소도구)
  • 번들된 확장 기능과 스킨
  • 서드파티 확장 기능과 스킨 (.wikven.yaml 참고)
  • 검색 (클라이언트 사이드, SifterSearch가 제공)
  • 여러 언어로의 번역 (Translate 확장 기능을 통해)

지원하지 않는 기능

다음 기능은 실제로 구동 중인 위키가 있어야 하므로 정적 내보내기에는 포함되지 않습니다:

  • 모든 특수 문서
  • 모든 편집기 (WikiEditor, 시각편집기, CodeEditor)
