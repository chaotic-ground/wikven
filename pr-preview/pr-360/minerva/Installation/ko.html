Wikven은 세 가지 방식으로 실행됩니다. Linux에서는 Docker가 필요 없는 단일 파일인 단독 실행 바이너리가 가장 간단합니다. macOS나 Windows에서는 Docker 이미지를 사용하십시오. Wikven을 수정하거나 아직 배포되지 않은 버전을 실행하려면 소스에서 빌드하십시오.

바이너리

x86_64와 arm64 Linux용으로 MediaWiki를 내장한 단일 자체 완결형 실행 파일입니다. 내려받은 뒤 실행 권한을 부여하십시오: 

curl -L -o wikven https://github.com/chaotic-ground/wikven/releases/latest/download/wikven-linux-x86_64
chmod +x wikven

arm64에서는 wikven-linux-aarch64를 사용하십시오. 이 파일을 PATH에 설치하는 방법, 나이틀리 빌드, 그리고 이 파일이 사용하는 선택적 호스트 도구에 관해서는 단독 실행 바이너리를 참고하십시오.

Docker

Docker가 설치된 모든 플랫폼에서 동작하므로, macOS와 Windows에서 사용할 선택지입니다. 이미지는 GitHub Container Registry에 게시됩니다: 

docker pull ghcr.io/chaotic-ground/wikven

태그가 없는 이미지는 최신 빌드를 따라갑니다. 특정 버전으로 고정하려면 :1.0.0 같은 배포 태그를 붙이십시오.

소스에서 빌드

Wikven을 수정하거나 배포되지 않은 커밋을 실행하려면, 저장소를 복제한 뒤 이미지를 직접 빌드하십시오: 

git clone https://github.com/chaotic-ground/wikven.git
cd wikven
docker build -t wikven .

이렇게 하면 게시된 이미지와 똑같이 실행할 수 있는 로컬 wikven 이미지가 만들어집니다. 대신 단독 실행 바이너리를 소스에서 빌드하려면 binary.Dockerfile을 참고하십시오.

Wikven을 갖추었다면, 시작하기로 이동해 첫 사이트를 만드십시오.
