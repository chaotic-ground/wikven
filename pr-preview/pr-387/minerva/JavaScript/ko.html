이 문서는 JavaScript 문서를 번역한 것이며 번역은 100% 완료했습니다.
다른 언어:
  • English
  • 한국어

Wikven은 빌드 시점에 위키 자체의 JavaScript를 정적 내보내기에 번들로 포함하므로, 구동 중인 서버나 load.php 없이도 사이트 스크립트와 소도구가 실행됩니다.

MediaWiki:Common.js

사이트 전역 JavaScript는 일반 위키에서와 마찬가지로 MediaWiki:Common.js에 둡니다. 소스 디렉터리에 MediaWiki:Common.js 파일을 만들면 모든 문서에서 실행됩니다. .js 문서는 자체 콘텐츠 모델을 가지므로 .wikitext 표시가 필요 없습니다. 스킨의 MediaWiki:Vector.js(등등)도 같은 방식으로 동작합니다.

소도구

소도구를 사용하려면 .wikven.yaml에서 번들된 Gadgets 확장 기능을 활성화합니다: 

extensions:
  - Gadgets

소도구는 MediaWiki:Gadgets-definition.wikitext에 나열하고, 각 소도구의 코드는 MediaWiki:Gadget-<name>.js에 둡니다: 

* MyGadget[ResourceLoader|default]|MyGadget.js

default로 표시된 소도구만 로드됩니다. 정적 사이트에는 다른 소도구를 켤 로그인한 독자가 없기 때문입니다. 소도구 자체의 CSS(같은 모듈에 있는)는 포함되지만, 스타일만 있는 독립형 소도구는 아직 지원되지 않습니다.

이 문서에는 그러한 소도구 하나인 PersistTabber가 포함되어 있는데, 이는 설치 단계에서 Docker 탭과 바이너리 탭 중 무엇을 선택했는지 기억합니다. 같은 문서에 있는 다른 탭도 모두 선택한 탭으로 함께 전환되며, 다른 문서로 이동해도 그 선택은 그대로 남아 있습니다.
