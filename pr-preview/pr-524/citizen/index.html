Bake wikitext into a website.

Wikven renders your wikitext through MediaWiki at build time and writes out plain HTML. Nothing runs behind the published site.

Getting Started
Installation

How it works

Every .wikitext file becomes a page.

Your source

src/
index.wikitext
Getting Started.wikitext
Template:note.wikitext
$ wikven build

Your site

dist/
index.html
Getting_Started.html
site.styles.css
pagefind/

the search index

What you get

Templates, not copy-paste

Templates, parser functions and Lua modules, all resolved at build time.

Extensions and skins

Bundled or fetched from Git, with several skins for the reader to choose between.

Search with nothing to query

The index is built with the site and runs in the reader's browser.

Every language you write in

Every language you write in comes out as its own set of pages.

Where it fits

A project's documentation, an archived wiki, a personal wiki. Unlike a general static-site generator such as Hugo or MkDocs, Wikven renders real wikitext, so it suits content that is already a wiki. See Why wikitext for how the markup compares with Markdown, and Limitations for what a live wiki does that a published site cannot.

Your first site is one command away.
