Wikven은 Wikipedia를 구동하는 소프트웨어인 MediaWiki 위에서 돌아가는 정적 사이트 생성기입니다. 위키텍스트를 쓰면 Wikven이 빌드할 때 MediaWiki로 한 번 렌더링해 평범한 HTML로 내보냅니다. 게시된 사이트 뒤에서 돌아가는 것은 아무것도 없습니다. MediaWiki도, PHP도, 데이터베이스도요. 

mkdir src
echo 'Hello, World!' > src/index.wikitext
wikven build

src/ 아래의 .wikitext 파일은 모두 dist/ 아래의 문서로 나옵니다. 이 사이트도 그렇게 만든 빌드 중 하나입니다.

위키텍스트를 쓰는 이유
설치
시작하기

틀·파서 함수·Lua 모듈 — 같은 것을 두 번 쓰지 않게 해 주는 위키 고유의 방법입니다. 전부 빌드할 때 실행되므로, 독자가 내려받는 것은 그 결과물뿐이고 뒤에 남는 장치는 없습니다.

확장 기능과 스킨 — 번들되어 있거나, 사이트를 만들 때 Git에서 가져옵니다. 스킨을 한꺼번에 여러 개 빌드하면 사이트에 전환기가 함께 실리므로, 어떤 모습으로 볼지는 독자가 고릅니다.

질의할 곳 없는 검색 — 색인은 사이트와 함께 만들어지고, 검색은 독자의 브라우저에서 이루어집니다.

여러 언어 — Translate 확장 기능의 작업 흐름을 빌드할 때 돌려, 언어마다 자기 문서 묶음으로 나옵니다. 이 사이트도 영어와 한국어로 쓰였습니다.

Hugo나 MkDocs 같은 범용 정적 사이트 생성기와 달리 Wikven은 진짜 위키텍스트를 렌더링합니다. 그래서 이미 위키인 콘텐츠에 잘 맞습니다. 프로젝트 문서 사이트, 평범한 HTML로 열람하는 보관용 위키, 개인 위키 같은 것이죠. 마크업이 Markdown과 어떻게 다른지는 위키텍스트를 쓰는 이유에, 구동 중인 위키가 하는 일 가운데 게시된 사이트가 할 수 없는 것은 제한 사항에 적어 두었습니다.
