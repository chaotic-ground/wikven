위키를 웹사이트로 구워 냅니다.

Wikven은 빌드할 때 MediaWiki로 위키텍스트를 렌더링해 평범한 HTML로 내보냅니다. 게시된 사이트 뒤에서는 아무것도 돌아가지 않습니다.

설치

어떻게 만들어지나

.wikitext 파일은 하나하나가 문서가 됩니다.

소스

src/
index.wikitext
Getting Started.wikitext
Template:note.wikitext
$ wikven build

사이트

dist/
index.html
Getting_Started.html
site.styles.css
pagefind/

무엇을 쓸 수 있나

복사·붙여넣기 대신 틀

틀과 파서 함수, Lua 모듈까지 전부 빌드할 때 처리됩니다.

확장 기능과 스킨

번들되어 있거나 빌드할 때 Git에서 가져오며, 스킨은 여러 개를 실어 독자가 고르게 합니다.

질의할 곳 없는 검색

색인이 사이트와 함께 만들어지고, 검색은 독자의 브라우저에서 이루어집니다.

개인 위키

Hugo나 MkDocs 같은 범용 정적 사이트 생성기와 달리 Wikven은 진짜 위키텍스트를 렌더링하므로, 이미 위키인 콘텐츠에 잘 맞습니다. 마크업이 Markdown과 어떻게 다른지는 위키텍스트를 쓰는 이유에, 구동 중인 위키가 하는 일 가운데 게시된 사이트가 할 수 없는 것은 제한 사항에 적어 두었습니다.
