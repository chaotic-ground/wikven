Bake a wiki into a website.

Wikven renders your wikitext through MediaWiki at build time and writes out plain HTML. Nothing runs behind the published site.

Getting Started
Installation

How it works

You run 

mkdir src
echo 'Hello, World!' > src/index.wikitext
wikven build

You get 

dist/
  index.html
  site.styles.css
  startup-static.js
  pagefind/

Every .wikitext file becomes a page.

What you get

Templates, not copy-paste

Templates, parser functions and Lua modules, all resolved at build time.

Extensions and skins

Bundled, or fetched from Git as the site builds. Ship several skins and let the reader choose.

Search with nothing to query

The index is built with the site and runs in the reader's browser.

Every language you write in

Each one comes out as its own set of pages.

Where it fits

A project's documentation

An archived wiki

A personal wiki

Your first site is three commands away.

Getting Started

This site is a Wikven build. Unlike a general static-site generator such as Hugo or MkDocs, it renders real wikitext — see Why wikitext for how the markup compares with Markdown, and Limitations for what a live wiki does that a published site cannot.
