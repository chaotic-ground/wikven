Wikven is a static site generator that runs on MediaWiki, the software behind Wikipedia. You write wikitext; Wikven renders it through MediaWiki once, at build time, and writes out plain HTML. Nothing runs behind the published site: no MediaWiki, no PHP, no database. 

mkdir src
echo 'Hello, World!' > src/index.wikitext
wikven build

Every .wikitext file under src/ comes out as a page under dist/. This site is one of those builds.

Why wikitext
Installation
Getting Started

Templates, parser functions and Lua modules — the wiki's own way of not writing the same thing twice. All of it runs at build time, so what a reader downloads is the result, with none of the machinery behind it.

Extensions and skins — bundled, or fetched from Git as the site is built. Build several skins at once and the site carries a switcher, so the reader chooses how it looks.

Search, with nothing to query — the index is built with the site and runs in the reader's browser.

Many languages — the Translate extension's workflow, run at build time; each language comes out as its own set of pages. This site is written in English and Korean.

Unlike a general static-site generator such as Hugo or MkDocs, Wikven renders real wikitext, so it suits content that is already a wiki: a project's documentation, an archived wiki to browse as plain HTML, a personal one. See Why wikitext for how the markup compares with Markdown, and Limitations for what a live wiki does that a published site cannot.
